# Key-Kingdom Brand Repository

This repository contains the **official brand specification** for Key-Kingdom, including:

- Master brand spec (`Key-Kingdom_BRAND_SPEC.md`)
- Design tokens (colors, typography, spacing)
- UI component rules
- Machine-readable brand data (JSON / YAML) for AI agents, design systems, and apps
“Dark mode neon blue / cyan brand”
## Files

- `Key-Kingdom_BRAND_SPEC.md`  
  Human-readable, full brand manual. This is the main reference for designers, developers, and AI models.

- `ui/TOKENS.css`  
  CSS design tokens for quick implementation in web projects.

- `ui/COMPONENTS.md`  
  UI component guidelines and usage notes.

- `api/brand.json`  
  Machine-readable brand schema for APIs, AI tools, or automated theming.

- `api/brand.yaml`  
  YAML version of the same schema.

## Usage

- For **design/dev**: start with `Key-Kingdom_BRAND_SPEC.md`.
- For **AI tools / agents**: feed them `Key-Kingdom_BRAND_SPEC.md` plus `api/brand.json` or `api/brand.yaml`.
- For **web projects**: import `ui/TOKENS.css` and follow `ui/COMPONENTS.md`.
